# Jozibroc Portfolio Website

A clean, responsive portfolio/business website for Jozibroc and Elizabeth Sambo.

## Files
- `index.html` — website structure and Meta Pixel installation
- `style.css` — responsive styling
- `script.js` — mobile menu, scroll reveal, WhatsApp guide selection and Meta Pixel events
- `assets/elizabeth-sambo.png` — supplied profile photo

## Run locally
Open `index.html` in a browser.

For development, you can also use VS Code + Live Server.

## Meta Pixel
The supplied Meta Pixel ID is already installed:
`851390221299784`

The site sends:
- PageView
- Lead when a WhatsApp CTA is clicked
- GuideInterest when a visitor selects a guide

## Before publishing
1. Replace the three placeholder testimonials with genuine customer reviews.
2. Add the real Jozibroc Facebook page URL if desired.
3. Connect your preferred payment/checkout system if you want visitors to pay directly on the site.
4. Test WhatsApp, Instagram and all buttons on mobile.
